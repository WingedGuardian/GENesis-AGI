# The graph engine (redis-server, redis-cli and the FalkorDB module), shipped as
# one pip wheel. Installed by scripts/lib/falkordb_install.sh BEFORE the editable
# install of Genesis, with:
#
#   pip install --only-binary=:all: --no-deps --require-hashes -r <this file>
#
# Why before: pyproject.toml declares the same pin, and the editable install
# would otherwise fetch the wheel first, trusting it on TLS alone. Installed here
# first, the editable install finds the requirement already satisfied.
#
# Why --require-hashes: the wheel carries native code that runs as the engine.
# pip refuses a file whose sha256 is not listed below, and installs nothing. pip
# does not re-check a wheel that is already installed, so the installed files are
# then checked again, on every provision, against the per-file digests committed
# in falkordb-engine-digests.txt (generated from these same wheel files), and the
# engine runs from a verified copy under ~/.genesis/deps/falkordb, never from the
# venv. The unit re-checks that copy's digest file on every start.
#
# Wheels are manylinux_2_38 (glibc 2.38, Ubuntu 24.04 and later) for CPython
# 3.12, 3.13 and 3.14 on x86_64 and aarch64; installers refuse any other OS or
# machine. To move the pin, replace the version and every hash together, from
# the wheel files themselves, and regenerate falkordb-engine-digests.txt from
# them in the same change (the command is in its header).
