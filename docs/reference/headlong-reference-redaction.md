# Contained Headlong reference-preserving redaction

This B-only experiment adapts the pinned prompt redactor in the disposable image;
stock `/headlong` remains unchanged. It does not activate a Genesis runtime or
establish native monolith continuity. The [native foundation](headlong-native-action-port.md)
and [stock controls](headlong-offline-controls.md) retain separate denominators.

The pinned grouped-card rule can change numeric groups inside valid UUIDs. It
reaches details commands, trigger/resolution/reply references, generated action
content and plain pending hints. Stored references and exact consumers remain
unchanged, so corrupted prompt references cannot reliably address their referents.
The original failing UUID is retained as a control rather than choosing favorable IDs.

The controller registers only exact canonical identifiers returned by successful
owned trajectory writers. B1 may additionally register identifiers from independently
validated complete prior native receipts. Raw record membership, UUID shape and
prompt metadata grant no exemption. The private ephemeral config adds `reference_ids`,
`trigger_id` and `invocation_id`; both readers validate current root/run/identity/
trajectory/trigger and parent-supplied nonce. The parent atomically publishes the
existing per-run config; missing, partial, stale or cross-case input fails. Cleanup
retires the owned case after children finish. This is no production approval store.

Only the two generic card applications change. Preserve a match only when its
removed span lies wholly inside a registered reference; crossing a reference
boundary fails with status65. Other patterns, order, replacements, literal-secret,
labelled-card and PEM treatment remain intact. Semantic reference multiplicities
are compared before/after the entire pipeline, including decoded JSON keys and
values. Losing any used occurrence fails; absent references require no occurrence.
An otherwise unchanged JSON record is rendered canonically when a registered
reference is escaped in its raw representation, so the final text pass sees its
literal identifier. Empty-registry and already-literal records retain stock formatting.
Secret masking wins and nothing restores removed text. Range arithmetic uses jq
`match` codepoint offsets consistently, including Unicode prefixes.

Explicit conflicts emit only a constant diagnostic. Compiler, dependency and
configuration failures are distinct and cannot pass a conflict control. The later
bridge must empty failed prompt files, report incomplete before SDK execution, and
preserve existing timer/reactive failure pacing.

The independent reference runner requires116 cases:58 byte differentials,48
registered/unregistered surface controls,4 conflict controls, spoofed metadata and
5 identifier/encoding controls. Both actual upstream sanitizer suites also run.
Host tests exercise owned jq primitives and config failure states without executing
upstream/native programs. Actual upstream execution is restricted to the same
unprivileged, read-only, network-disabled disposable CI boundary. Source hashes,
container metadata and reports are retained; a passing report is required before
claiming qualification. Review and exact-head contained results remain separate
from source presence or local tests.
