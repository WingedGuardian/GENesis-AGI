- `--check-pr` prints an advisory `delivery` row: whether the owner recorded a read that the PR delivers what its issue asked, at which head, and whether the base, the issue or the PR's basis changed since. A builder's own read counts only on a prose-only PR, where the row says `self-attested`. The row never blocks a merge, and `scripts/delivery_marker.py` is now on the enforcement-hook surface.
