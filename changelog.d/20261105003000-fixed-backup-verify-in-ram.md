- **The backup's database check no longer stalls the disk.** Every backup proves its SQLite copy restores by decrypting it and rebuilding the whole database from it. That rebuild now happens in RAM (`/dev/shm`) when there is room for it plus a fifth of memory spare, and on disk as before otherwise; the backup log says which and why. On a btrfs root the on-disk rebuild held up filesystem writes for up to a minute every six hours. `GENESIS_BACKUP_VERIFY_TMPDIR`, `GENESIS_BACKUP_VERIFY_RAM_FACTOR` and `GENESIS_BACKUP_VERIFY_RAM_FLOOR_PCT` tune it.
