- **Claude Code failure events are no longer merged across inbox sessions.** When two inbox batches failed the same way within a minute, only the first got a `cc.invocation_failed` event and the second's failure was counted on whichever session failed next. Repeated failures are now coalesced per session, so each batch's failure is reported against its own session. A session that stops failing has its swallowed count reported within about two minutes, without waiting for another failure, and that report is dated to the session's last failure, so the Errors view no longer shows a finished session's error as still active.
