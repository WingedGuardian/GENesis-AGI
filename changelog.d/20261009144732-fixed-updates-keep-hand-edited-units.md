- **Fixed: an update no longer silently overwrites a systemd unit you edited by hand.** `scripts/update.sh` used to re-render every unit under `~/.config/systemd/user` from its template, discarding any change made in the unit file itself, with nothing in the output saying so. Each rendered unit now ends with a `# genesis-managed` stamp, and an update that finds an edited unit refuses before stopping anything (exit 4), naming the unit and the two fixes: move the change into a drop-in (`<unit>.d/override.conf`, which updates never touch), or run `scripts/update.sh --take-template <unit>` to install the template, with the old file saved under `~/.genesis/deploy-backups/`. The VNC units `scripts/setup-vnc.sh` writes are covered the same way. Timers listed in `~/.genesis/config/disabled_timers` stay off across updates (`systemctl mask` cannot work on these units). Every update now ends with a list of what it changed outside the checkout: units written or kept, timers skipped, Claude Code pin realignments and removed shadow copies.
