- When the review escalation gate blocks, the remedies it offers are now put to you directly. Previously the gate printed its options and the session relayed them — which is how a real block once reached the user with the first option missing, a fourth invented, and "ship as-is" added. The gate's own question is now appended to the session's next question automatically, with the gate's own wording, so the menu you answer is the one the gate wrote. Acknowledging the block with `# escalation-ack` or `# audit-ack` no longer works on its own once the gate has actually blocked: your recorded choice is required too. Choosing to hand the work back or shelve it is final and the sigil cannot override it — `python3 scripts/review_state.py retire-gate-demand` re-opens the question so you can be asked again, but leaves the work blocked until you answer. `python3 scripts/review_state.py gate-demand` shows what is currently on record. Turn the whole mechanism off with `GENESIS_GATE_ACK_DISABLED=1` or by creating `~/.genesis/config/gate_ack_disabled`.
- Background (dispatched) sessions can no longer acknowledge their way past the escalation gate. There is nobody to ask, and answering on your behalf is exactly the attestation the gate exists to make real — so such a session now stops and is told to hand the branch back with a `needs-architecture-session` label and a follow-up naming the decision it is waiting on. This is a deliberate reduction in what an unattended session can do, in the same class as its already being unable to open a pull request.
