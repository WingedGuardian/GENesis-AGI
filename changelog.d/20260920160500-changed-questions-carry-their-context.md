### Changed

- A question that needs an answer must be **asked through the question tool and
  carry the context to answer it**, and must be **re-asked** if it goes
  unanswered while it still blocks. Two failures were compounding: a question
  posted as prose in the body of a message competes with everything else there
  and gets missed, and a question offering bare options ("fix it or hand it
  back?") asks the reader to supply the analysis the session was supposed to do.
  The result was questions that sat unanswered for days while being restated
  each turn as open items and worked around. Options now state what each one
  costs, state carries an explicit as-of (verified now, not recalled from a plan
  or a prior summary, which go stale), and the cost of deciding nothing is named
  alongside the choices.
