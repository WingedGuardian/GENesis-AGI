- A PostToolUse hook, `scripts/hooks/pr_opener_stamp.py`, adds `Opened-by-session: <8hex>` to a pull request's body right after a Claude Code session opens it with `gh pr create` (the prefix its commits' `Genesis-Session` trailer already carries), so `scripts/pr_opener.py <N>` names the opener from the body. When a later body rewrite drops the line, the hook restores it with the original opener's id from the PR's edit history. It stamps only the install's own repositories, can wait for a body-editing bot's first edit (`config/pr_opener_stamp.yaml`, overridable per install), never blocks, and names what it could not do.
- `scripts/pr_opener.py` reads an `Opened-by-session-correction` line from the PR's edit history as well as its current body, so a correction stands after a body rewrite drops it, until a newer correction replaces it; one the PR was opened with (copied from another body) still never counts.
