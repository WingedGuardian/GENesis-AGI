- **`scripts/install_browser_stack.sh` now installs and upgrades the Camoufox engine.** The new engine (Firefox 156, a 1.3 GB download) is fetched into a staging directory next to the current one, which stays in place until the new engine has launched successfully from where it was downloaded; then the two are swapped and an old pre-0.5 engine is kept as a dated backup. An install already in camoufox 0.5's side-by-side layout gets the new version added in place. A `camoufox set` choice of another build is reset to the paired build. If the fetch or the launch check fails, or the run is interrupted before the swap, the previous engine is untouched and the previous browser packages are restored. A staging directory left by a run that was killed outright is removed at the next run. When the browser tools find the engine missing, they now point to this script.
