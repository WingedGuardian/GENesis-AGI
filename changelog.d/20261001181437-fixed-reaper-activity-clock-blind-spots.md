- **The worktree reaper no longer mistakes a recently changed worktree for an idle one.** Its activity clock missed several kinds of change below its shallow scan: a deletion or rename (which leave no new mtime on the file itself), a path git quotes because it holds unusual bytes, and an edit inside a submodule. It also archived a worktree edited while the scan was running. The clock now reads git's unquoted status, counts the directory a file was added to, renamed in or deleted from, and reads a submodule's own status. Right before archiving, the reaper re-checks the worktree's age in both lanes and skips one touched since it was classified.
