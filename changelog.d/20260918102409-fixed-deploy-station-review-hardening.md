- **Code-only deploys and live validation runs now share one deploy-station lock.** `scripts/deploy_code_only.sh` pulls, reinstalls and restarts under an exclusive hold that also excludes `update.sh`, stands the watchdog and the host guardian down for the restart window, verifies health afterwards, and raises a critical alert (never an automatic revert) when a step after the tree advanced fails. `scripts/run_under_deploy_lock.sh -- <cmd>` holds the lock shared, so a deploy cannot restart the server mid-validation, and forwards termination to the wrapped command. The fetch is time-bounded, a worktree copy is refused, and a killed deploy leaves only a dead PID marker behind, never the full update's crash-recovery record that bootstrap would act on.
