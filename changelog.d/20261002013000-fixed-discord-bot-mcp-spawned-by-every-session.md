- **Interactive Claude Code sessions no longer start the Discord MCP server.** `.mcp.json` copied every server from `config/mcp.json.template`, so each interactive session spawned `discord-bot` too, even though only the `community-responder` background profile uses it. The render now leaves out servers that only a dispatch profile uses. The template still lists them, so `community-responder` keeps its Discord tools. This also covers conversation-channel sessions and any dispatch on the `full` MCP profile, which load the same `.mcp.json`; Discord tools are now available only to `community-responder`. `install.sh` now renders `.mcp.json` with the same script `bootstrap.sh` runs. Existing installs pick the change up at their next `bootstrap.sh` (which `update.sh` runs on every applied update; a code-only deploy does not re-render it), and in sessions started after that.
