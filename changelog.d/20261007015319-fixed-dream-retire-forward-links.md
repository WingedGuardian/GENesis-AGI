- **The dream cycle now records which memory replaced one it retires.** Both consolidation paths (synthesis and duplicate merging) write the successor to the memory database, not only to the vector index, and rolling a run back clears it again. A synthesis that turns out to be an exact copy of one of its own source memories is now skipped instead of retiring that memory, and an explicit supersede on a dream-retired memory can no longer be silently redirected to the dream's successor.
