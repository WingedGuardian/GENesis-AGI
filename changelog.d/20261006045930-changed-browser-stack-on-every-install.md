- **The browser stack is now installed and kept current on every install.** Bootstrap and the installer run `scripts/install_browser_stack.sh`, and the updater runs it after the update is recorded as done, including when there is nothing new to apply, so re-running the update retries a step that was skipped; the first upgrade's download (about 2 GB, about 3 GB unpacked) does not lengthen the server's stop window. When the browser packages already match, the step runs no pip install. The step is non-fatal: its last line is the outcome, the installer warns when Camoufox is not usable (the Chromium fallback needs the display that bootstrap's VNC step sets up, so the installer only notes it), and the `browser_automation` capability reports the end state. On the update that first ships this, the updater still running is the previous version, so the step waits for the next run of the updater (or run `scripts/install_browser_stack.sh`); the installed browser keeps working meanwhile. After the browser packages change, Claude Code sessions that were already running must be restarted before their browser tools work; the step says so.
