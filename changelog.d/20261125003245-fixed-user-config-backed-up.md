- Settings you change from the dashboard or by asking Genesis are now included in the 6-hourly backup, encrypted, and restored on a rebuilt box. They live in `~/.genesis/config/`, which the backup did not cover before. If you had listed that folder in `GENESIS_BACKUP_EXTRA_DIRS`, remove it: the backup now covers it and notes that the entry is no longer needed. A restore keeps a settings file that is already on the box unless you pass `--force`, and `--force` keeps a copy of the replaced file under `~/.genesis/restore-displaced/`. A settings file the backup cannot capture is reported as a gap in the backup status and alert. Deleting a settings file does not delete its backed-up copy, so a restore brings it back; delete it again afterwards if you meant it. After a passphrase change, a kept copy of a file you have since deleted can no longer be opened; the backup moves it once into an `unopenable/` folder in your private backups repo (kept, but not uploaded or restored) and alerts you that one time. A backup without its passphrase now reports identity and settings files as not captured.
