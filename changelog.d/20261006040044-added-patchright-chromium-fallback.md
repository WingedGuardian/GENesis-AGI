- **The Chromium fallback browser now uses patchright, and the browser step installs its Chromium.** patchright is Playwright with the Chromium automation leaks patched; the fallback uses it with its documented stealth setup (the real window size, no emulated viewport), and falls back to plain Playwright, with a warning, only when patchright is not installed (an installed but broken patchright is reported instead). `browser_run_js` still evaluates in the page's own JavaScript context on patchright pages. `scripts/install_browser_stack.sh` installs patchright's Chromium, copies the Chromium profile before a different Chromium build first opens it, and checks that Chromium launches exactly as the fallback does (headed on the VNC display, on its own profile); a profile last opened by a newer Chromium is left alone. When the launch fails for missing system libraries, the step installs them through non-interactive sudo, or prints the command to run; a missing display is named instead. A Chromium failure never rolls back the browser packages, because Camoufox is the primary browser. Chromium profile backups are pruned after 14 days only once the installed Chromium has opened the profile.
