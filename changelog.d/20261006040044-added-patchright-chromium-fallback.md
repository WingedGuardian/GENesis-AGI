- **The Chromium fallback browser now uses patchright, and the browser step installs its Chromium.** patchright is Playwright with the Chromium automation leaks patched; the fallback uses it with its documented stealth setup (the real window size, no emulated viewport), and falls back to plain Playwright, with a warning, only when patchright is not installed (an installed but broken patchright is reported instead). `browser_run_js` still evaluates in the page's own JavaScript context on patchright pages. `scripts/install_browser_stack.sh` installs patchright's Chromium, copies the Chromium profile before a newer Chromium first opens it, and checks that Chromium launches; if it does not, it installs Chromium's Linux system libraries through non-interactive sudo, or prints the command to run. A Chromium failure never rolls back the browser packages, because Camoufox is the primary browser. Chromium profile backups are pruned after 14 days only once the new Chromium has opened the profile.
