- **Graph-engine fallbacks are now recorded durably.** Every memory-graph traversal (recall enrichment, memory expansion, drift queries and the ambient worker) records which graph store was configured, which one answered, and why they differed, in the evaluation events table, kept 30 days. This is the evidence the FalkorDB default-on decision waits on; until now those fallbacks only reached logs, and from the MCP memory server not even that. Set `GENESIS_GRAPH_TELEMETRY_DISABLED=1` to turn it off.
