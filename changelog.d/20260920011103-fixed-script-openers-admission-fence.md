- Script-side hooks and workers (audit trail, edit sensor, precompact, procedure advisor, proactive memory, session context/heartbeat/alerts, repo pulse, snapshot GC) no longer read or write a database once its quarantine or maintenance marker is visible — the corruption-recurrence path where hook writers bypassed the quarantine marker. They now consult a shared admission fence (`genesis.db.admission`, read side) and silently skip the database while it is quarantined or held for maintenance, resuming on their own once it is released.
