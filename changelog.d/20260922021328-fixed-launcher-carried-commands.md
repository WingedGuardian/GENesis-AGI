- The safety guards now see a command run through `eval`, `su -c`, `runuser`, `setpriv` or `chroot`. Previously the guards resolved only the launcher, so a removal of a protected directory or a push behind one of them ran unchallenged while the same command typed directly was stopped. The guards no longer try to model each launcher's option grammar — they refuse conservatively when a launcher they cannot resolve names something protected, so a carried command that touches nothing protected still runs.
