- **Editing CONVERSATION.md or STEERING.md in the dashboard now saves into this install's `CONVERSATION.local.md` or `STEERING.local.md`, never the tracked file.** The editor shows the text sessions actually read (the shipped file plus the local rules). An edit that only adds after the shipped text is stored as additions, so later shipped changes still arrive; any other edit is stored as a replacement, and the text sessions read then says the shipped file is replaced. A save made after the text changed underneath the editor, such as a steering rule captured while it was open, is refused with a prompt to reload, so the captured rule is never silently dropped. A deploy no longer refuses a checkout because someone edited one of these two files in the dashboard. SOUL.md and VOICE.md are still edited in place until they become per-install copies later in this series.
