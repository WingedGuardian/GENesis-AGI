- **The memory hook no longer offers hidden memories as breadcrumbs.** The `→ id:x` hints attached to the top delivered memories read strong links without the visibility rule normal recall and graph traversal follow, so a deprecated or expired memory could be offered — and recorded in the recall trace as a shown hint. Those neighbours are now dropped before the two-per-memory cap, so a visible neighbour takes the slot, and a neighbour linked by two relationship types is offered once; hints with no hidden neighbour are unchanged. If the visibility read fails, the prompt gets no breadcrumbs rather than unchecked ones.
