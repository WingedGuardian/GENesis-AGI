- Added foreground `gmodel` routes for Kimi K3 and MiMo V2.6 Pro, with subscription, direct API and OpenRouter choices and automatic credential-based selection that says why it picked a per-token route. A routed session's endpoint, credential, model, context window, effort and compaction/thinking settings are pinned for the whole session, so editing a settings file mid-session cannot re-route it; a `maxEffortLevel` cap in any settings file still applies, and `gmodel` warns about one at launch. The Kimi subscription route reads `KIMI_CODING_API_KEY`, the same key as the Kimi Code roster example.
