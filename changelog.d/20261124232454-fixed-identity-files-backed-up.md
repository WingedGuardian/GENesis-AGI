- Your `USER.md` profile is now included in the 6-hourly backup, encrypted, and restored on a rebuilt box even after setup has written a fresh template there. Identity files you customise locally later (`*.local.md` layers, and seeded copies of shipped defaults) are covered the same way. A restore never replaces an identity file you have edited (anything other than a fresh template) unless you pass `--force`, and `--force` keeps a copy of the replaced file under `~/.genesis/restore-displaced/`. A file the backup cannot capture, or one whose name the off-site restore could not read back (use letters, digits, `.`, `_` and `-`, not starting with `-`), is reported as a gap in the backup status and alert. A restore without the backup passphrase now stops before it starts whenever the backup holds encrypted files; before, the check could miss them when some backup folders were absent. Deleting an identity file does not delete its backed-up copy, so a restore brings it back; delete it again afterwards if you meant it.
