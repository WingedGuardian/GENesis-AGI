- **The holdout fence no longer records a plain directory listing as an exposure.** A tool result that only names the holdout directory now goes to the activity log with no note when the call is a shell command made only of commands that print names or their own arguments (`du`, `ls`, `stat`, `find` with no action, `echo`, `printf`, and `sort`- or `head`-style filters of their output), run directly, on the holdout or on a directory above it. Before, a routine `du -sh ~/.genesis/*` or `find ~/.genesis -maxdepth 1` wrote a permanent exposure and marked scenarios as possibly spoiled. Anything else that names the directory is still an exposure: a recursive `grep`, `find … | xargs head`, a wrapper, a command substitution, `eval`, an input redirect, an option that reads a file, `git` or `gh`, or a result from another tool. Those can print scenario lines under that path.
