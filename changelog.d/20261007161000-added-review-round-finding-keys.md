- The review-round evaluator (`scripts/review_budget.py`) now reports what a round reflection must answer for: an immutable key per finding in the open round (`c<comment id>`, `r<review id>/<k>` for a finding in a review body, `i<comment id>` for a Codex findings comment), whether every key could be read, which reviewers reported on the current head, and which reviewers took part in earlier rounds. Ids are read from GitHub's `fullDatabaseId` (the older `databaseId` is deprecated). A missing id never changes the round count or status; it only marks the keys unknown.
