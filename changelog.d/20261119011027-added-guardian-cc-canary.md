- **The Guardian now checks every day that its recovery brain can actually sign in, and waits longer before declaring Genesis dead after a host reboot.** A daily canary makes one tiny real Claude Code call through the same credentials the Guardian uses when Genesis is down, and pages once (with Claude Code's own reason) if it fails, then an all-clear when it works again. Before, a broken recovery brain was discovered only during an outage. And a failure that starts within 20 minutes of a host reboot now gets a 20-minute grace instead of 5: a cold boot of the container stack measured about 14 minutes, so the old grace paged "Genesis down" while it was still starting.
