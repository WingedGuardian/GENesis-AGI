- When a Claude Code Bash command's output file (`tasks/*.output`) is filling the Claude Code temp volume, the disk guardian now pauses that task's command and empties the file, instead of only reporting it. It acts only on that one kind of file, only once the volume is orange or red, and only in act mode. The command is paused (`SIGSTOP`), never killed, and the session itself is never paused. The last 1 MB of output is kept in `~/tmp/watchgod-truncated` when there is room, and a page explains how to resume. A command still paused after 6 hours (`DG_RUNAWAY_REPAGE_H`) is paged again, once per period. `scripts/watchgod status` lists paused processes; `scripts/watchgod thaw <pid>` or `thaw all` resumes them. Every other file, on every disk, still only triggers an alert.
- The Claude Code temp volume gets its own small reserve file (5% of the volume, up to 128 MB). It is released at red, after the guardian has had one poll to stop a runaway writer, so sessions keep enough space to work while the guardian recovers.
