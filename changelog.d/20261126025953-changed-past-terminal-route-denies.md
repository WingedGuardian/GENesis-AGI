- Past the terminal review round, an agent's `git push` onto the pull request's branch (in any spelling), `gh pr update-branch`, and an `@codex` mention once the head has moved off the terminal head are now refused, with the owner's bang command named in the message. An agent can no longer delete or edit a comment on an open pull request, through `gh`, the REST API or the GraphQL comment mutations, so `delivery_marker.py compose` now prints a command that posts a re-read as a new comment, which supersedes the old marker. When the review budget cannot be read, pushes and comments behave as before, and past terminal the stale-base note now says to send the PR back instead of updating its branch.
