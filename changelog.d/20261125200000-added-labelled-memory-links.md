- Graph neighbours returned by `memory_expand` and `memory_recall`, and the proactive hook's `→ id:` hints, now carry a short label of the linked memory's own text and a plain relation (`similar`, `linked`, a typed link, or `via …` two steps away), so a session can judge a link before following it. Credential entries, external or unknown-origin text, and hidden memories the caller did not ask for get no label. An expand records its session and each hook recall records the hint ids it showed, so followed links can be counted per session.
