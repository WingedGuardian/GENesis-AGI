- A credential reference now keeps its value in a separate `reference_secrets` table, and its indexed body carries a placeholder line that names `reference_lookup`. `reference_lookup` and the dashboard reveal read the value from that table. Parts of the value repeated in the description, identifier or tags read `[redacted]`. Existing references are rewritten by a follow-up change. Re-saving a credential with only its placeholder still redacts the stored value from the description, identifier, tags and source fields, and a credential whose indexed text would still carry part of its value is refused. A credential never shares a search vector with another entry, and a refused save leaves no vector behind. `reference_lookup` returns a description and value saved together, even when the entry changes while it reads.
