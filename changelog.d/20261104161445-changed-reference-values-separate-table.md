- A credential reference now keeps its value in a separate `reference_secrets` table, and its indexed body carries a placeholder line that names `reference_lookup`. `reference_lookup` and the dashboard reveal read the value from that table. Parts of the value repeated in the description, identifier or tags read `[redacted]`. A credential captured automatically from a conversation never replaces one already stored under the same name: it is kept as its own entry. Existing references are rewritten by a follow-up change.
