- **The secrets guard now recognises the file named after an option prefix.** A word such as `--opt=secrets.env`, `@secrets.env` or `a:secrets.env` hands the program the part after the `=`, `@` or `:`, and many programs open it. The guard tested only the whole word, so it never matched. Each part is now checked as a path of its own. Globs and expansions still apply to the whole word only, as in bash.
