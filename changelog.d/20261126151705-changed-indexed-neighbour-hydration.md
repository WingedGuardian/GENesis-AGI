- **Recall with graph expansion no longer scans the whole full-text index to read its neighbours.** Graph expansion and the entity lane now read each neighbour by id, so the read costs about 9 ms for 25 neighbours instead of about 65 ms on a 50,000-memory benchmark, and it no longer grows with the index. A neighbour that was never embedded (an FTS-only subsystem write, or one still pending or failed) has no vector point, so its text is still read from the full-text index. That read runs only when such a neighbour is asked for.
