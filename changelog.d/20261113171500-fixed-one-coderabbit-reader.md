- **The review round counter and the review budget now read CodeRabbit findings the way the merge gate does.** Each used to read every line of a CodeRabbit comment as a possible severity header. A Major header quoted inside fenced code or a `<details>` section could therefore count as a floor finding the merge gate never scored. A Trivial comment ending in a plural `_Sources: …_` footer also opened a review round. All three readers now share the merge gate's code for skipping fenced and collapsed content and for splitting a comment into findings. The round counter now opens fewer rounds in two cases only: a header quoted in fenced code or `<details>`, and a plural source footer. It still counts a Major written after a Trivial with no separator between them. On the 523 most recent CodeRabbit comments, no reading changed.
