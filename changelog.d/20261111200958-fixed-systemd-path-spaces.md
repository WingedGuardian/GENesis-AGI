- **Services no longer lose most of their PATH when a directory on it contains a space.** The systemd units wrote `Environment=PATH=…` unquoted, so a space in a PATH entry (seen live with the Claude Code bin directory resolving to a Windows npm directory under `/mnt/c/Users/<First Last>/` from WSL) cut PATH at the space: genesis-server ran without `/usr/bin`, so `pgrep`, `gh` and `systemctl` failed at runtime. Every unit's PATH, and every other environment variable a unit sets from an install path, is now quoted and escaped for systemd. Run `scripts/update.sh` (or `scripts/bootstrap.sh`) to re-render the units on an existing install. A home or clone directory with a space in it is still not supported: the units' `ExecStart=` lines split on it.
