- **Updated the routed model versions, and gave the version-bearing provider names neutral ones.** The routing table had drifted behind the providers, so several call sites were asking for models that had since been superseded. Providers now point at current models, and the seven whose names encoded a version (`glm51`, `kimi-k2.5`, `minimax-m25`, `openrouter-deepseek-v4-flash`, `openrouter-gpt55`, `gpt-5.4`, `openai-gpt5`) were renamed so the name no longer lies about what it serves. If you keep a local routing overlay, check it against the new names — an overlay still referencing an old one will not resolve. Call-site chains that had **no paid provider at all** now end in a paid last-resort rung, so a site that previously failed outright once every free provider was down has somewhere left to go. Those rungs only fire after every free rung has failed. Because they make the daily spend cap reachable from sites that previously could not spend, the default daily/weekly/monthly budgets for **new installs** are raised from $2/$10/$30 to $5/$15/$50 — crossing that cap makes the router drop paid providers from every chain, including the contingency lane. Existing installs keep whatever budget their operator set; the new default applies to installs created from here on and is not pushed onto anyone retroactively.

Two things this change deliberately does NOT touch: the NVIDIA NIM DeepSeek provider, whose model reached end of life and now answers HTTP 410 (18 call sites reference it, and NIM serves no DeepSeek replacement, so repointing them is its own decision), and the eight providers that are defined but wired to no call site.
