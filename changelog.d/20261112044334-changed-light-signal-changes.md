- **Light reflections now see what changed since the previous run, and a quiet run stays off the Light topic.** The Light prompt carries a table, computed by code, of each signal's previous and current value, labelled as a counter that moves every run, an alarm that started, cleared or got worse, or a band crossing; a cleared alarm, which the zero-filtered signal list hides, now shows there. Light's own job is the part code cannot settle: whether a move that crosses no line deserves attention. A summary the model marks as no change is kept off the topic only while code finds no condition change since the last summary that was actually posted. When it does find one, the summary is posted with those changes listed, whatever the model said. That check replaces the comparison of wording, which rejected about half of honest no-change summaries. A Genesis version change is no longer shown to the Light reflection, so it stops leading Light summaries.
