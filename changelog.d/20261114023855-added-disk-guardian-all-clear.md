- **Added: the disk guardian now says when a disk it paged about has recovered.** After an ORANGE or RED page, the first poll that finds the filesystem back to GREEN sends one message saying so, with the free space and how far the episode got. Before, a page was never followed by anything, so a disk that recovered a minute later looked the same as one still filling. Pages that never reached the queue get no all-clear, an all-clear is suppressed exactly when its page was, and an all-clear that cannot be queued is logged without delaying the next alert.
