- **The safety guards now refuse text the shell builds while it runs.** A command that writes part of its text as an escape inside `$'…'` quoting (a letter, a newline, or a character given by its code) is treated like a command split across lines: when it names an operation a guard checks, the guard refuses it and says to write that text out plainly. The discard guard and the commit gate also refuse a git command whose subcommand is not written out (a variable, a substitution or an escape stands in its place), as the push guard already did. Layout escapes such as a tab, and variables in ordinary arguments, work as before.
