- The pull-request reviewers the merge gate trusts are now declared in `config/reviewers.yaml` (Codex as the primary reviewer, Devin and CodeRabbit as possible stand-ins, CodeQL shown but never counted) instead of being written into the gate's code. For now the merge gate reads two things from it: which reviewer merge freshness requires, and which may stand in for it under `# substitute-review`; an install can change either with one line in `~/.genesis/config/reviewers.local.yaml`. A malformed reviewer file blocks merges with a message naming the config error, rather than silently dropping a reviewer.
