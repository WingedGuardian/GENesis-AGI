- **The browser step backs up the Camoufox profile before a different Firefox build first opens it.** Firefox refuses a profile last used by a newer build, so `scripts/install_browser_stack.sh` copies `~/.genesis/camoufox-profile` to a dated `camoufox-profile.pre-v<old build>-<time>` directory before installing another engine; a retry after a failed upgrade refreshes that copy instead of keeping the first one, and going back to an older build never replaces the copy that build needs. If the copy fails (for example, no space), the upgrade stops before the engine is touched and the previous browser packages are restored. The daily disk-hygiene run removes these profile backups and the moved-aside pre-0.5 engine only once the new engine has opened the profile and 14 days have passed since then, so a broken install, or an upgrade nobody has browsed with yet, keeps its way back; a half-written copy left by a killed run is removed after a day.
