- **The browser step backs up the Camoufox profile before a newer Firefox first opens it.** Firefox refuses a profile last used by a newer version, so `scripts/install_browser_stack.sh` copies `~/.genesis/camoufox-profile` to a dated `camoufox-profile.pre-v<old>-<time>` directory before installing a newer engine; a retry after a failed upgrade refreshes that copy instead of keeping the first one. If the copy fails (for example, no space), the upgrade stops before the engine is touched and the previous browser packages are restored. The daily disk-hygiene run removes these profile backups and the moved-aside pre-0.5 engine after 14 days, but only while the current engine is ready, so a broken install keeps its way back; a half-written copy left by a killed run is removed after a day.
