- **Every page `web_fetch` returns is now marked as untrusted content.** Pages fetched through TinyFish, Firecrawl, Crawl4AI or the Ladder backend used to reach the calling session unmarked; only the plain HTTP path wrapped them. All of them now arrive inside the same `<external-content>` boundary, and so do the other fields a page supplies in a batch (title, description, author, and error text echoed back), so sessions reading fetched links, including the inbox evaluator, can tell the page's text from their own instructions. The clean-up that runs before wrapping now also neutralises boundary markers a page nests inside one another, which it previously left partly intact.
