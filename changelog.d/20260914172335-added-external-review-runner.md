- Pull requests can now be reviewed automatically by an external review orchestrator — a separately-installed tool, such as one of the agentic workflow runners, that reviews a pull request and posts its report as a comment. An hourly timer picks up open pull requests whose current head has no report yet and whose checks are green, and dispatches one review per tick. Genesis ships the adapter only: `config/external_review.yaml` is empty as shipped and dispatches nothing until an install names its own tool and the workflows it may run, so an existing install is unaffected until you opt in. The timer is rendered but not enabled; `GENESIS_EXTERNAL_REVIEW_DISABLED=1` and `mode: off` stop it.
