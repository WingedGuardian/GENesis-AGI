- A memory-pressure kill can no longer end every interactive Claude Code session at once. Each slot, and each interactive `gmodel` or bashrc `claude` launch, now starts in its own systemd scope, so systemd-oomd ends at most that one session; before, every slot shared the tmux server's cgroup and was killed with it. A tmux server started by the slot door also gets a scope of its own, so restarting the Genesis server after opening the dashboard terminal no longer ends every slot. Slots started before the update move when they are relaunched; without a systemd user manager, launches work as before.
