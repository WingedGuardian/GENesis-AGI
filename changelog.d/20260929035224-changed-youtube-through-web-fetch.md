- **The inbox evaluator no longer has shell access, and YouTube videos come through `web_fetch`.** The evaluation session reads untrusted content, so it now runs without Bash. The genesis `web_fetch` tool returns a YouTube video's title, channel, description and transcript. It picks captions in the video's own language (manual before automatic) and says which track it used, falling back to an audio transcription when there are none. Previously only English automatic captions were tried, and non-English videos often came back with no transcript at all. Every yt-dlp call ignores user config files and cookies, stays on YouTube hosts, and verifies certificates. A new `youtube_fetch` setting (`tls: verify | auto_fallback | off`) controls what happens on a certificate error; the default retries that one call once without verification and flags the result. `audio_max_minutes` (default 120) limits the audio-transcription fallback to videos of that length or less, read from the metadata before anything is downloaded. `yt-dlp` is now a declared dependency, with its JavaScript challenge solver installed locally.
