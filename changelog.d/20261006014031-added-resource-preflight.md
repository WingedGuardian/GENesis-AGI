- **A session can ask whether a heavy job fits before launching it.** `python -m genesis.hostmetrics preflight --name N --ram GB --cpu PCT` answers GO, WAIT, NO or ASK (exit 0, 3, 2, 4) against a configurable share (default 80%) of the container's memory, CPU and disk, counting current load and, when the guardian is configured, the host's free memory too. `status` prints the readings it uses. Tune it with `GENESIS_RB_*` variables or `~/.genesis/resource-budget.env`; see `docs/reference/resource-budget.md`.
