- **The guardian gateway has a `set-timezone <zone>` verb, and the host Guardian's snapshot-deletion window follows the host clock's zone.** The verb validates an IANA zone name, then sets the host clock's zone and the container's with the same calls the installers make; host jobs then run at local time, as on a fresh install. With no zone configured on the host, the deletion window now uses the host clock's zone (a UTC host clock still reads as "no zone chosen", so `disk-status` keeps reporting `fallback`), and Guardian log lines carry their UTC offset.
