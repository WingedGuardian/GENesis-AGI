- **The server and agent-zero units load one secrets file, chosen when they are rendered.** Each unit's `EnvironmentFile=` is now `-` plus the file the resolver picks when bootstrap or install renders it, so the units and the Python readers name the same file, and a missing file no longer stops either unit (the server raises its critical alert instead, and restores the file when a backup exists). The dashboard edits an existing secrets file but no longer creates one: it answers 409 and points to bootstrap, because a writer that cannot see an existing file elsewhere would otherwise create a template-shaped one that every reader then prefers.
