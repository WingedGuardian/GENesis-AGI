- **The dashboard's file browser no longer writes CONVERSATION.md or STEERING.md in place, and warns before dirtying the main checkout.** Opening either file in the file browser shows the text sessions read, and saving stores the edit in this install's `CONVERSATION.local.md` or `STEERING.local.md`, the same way the config editor does (including the refusal of a save made after the text changed). A `.local.md` file there cannot be written, created or renamed directly. Saving any other file that git tracks in the main checkout still works, but now says that the next deploy will refuse the dirty tree until the change is committed or reverted; files in a worktree save without a warning.
