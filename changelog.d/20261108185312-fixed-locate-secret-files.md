- **`locate` no longer returns lines from credential files.** A content search (`contains`) over the repo used to search `secrets.env`, its backups, `.env` files, private keys and token files like any other file and return the matching lines, which in those files are the secrets themselves. Content search now skips any file the dashboard's file routes already treat as a credential (the predicate moved to `genesis.security.credential_names` and is shared), plus the configured secrets file under any name (matched by inode), and it no longer walks `.config` directories. Skipped files stay findable by name, and the response counts them in `content_skipped_credential_files`, so a skip never reads as "no match". Stored credentials are read through `reference_lookup`, which audits each read.
