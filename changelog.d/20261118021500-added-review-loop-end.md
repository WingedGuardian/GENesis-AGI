- **Past round 4, a review loop ends.** Once the newest review round a fix produced is round 5 or later and draws no blocking finding, the commit gate stops content commits on that PR: it can be merged, sent back, or have a real defect carried in a new PR. Read from the review data alone. The round-4 and round-5 thresholds now count only rounds a fix produced, so rounds from merging main never push a PR toward them. The past-round-4 reflection rules switch on with this change.
