- Every merge through the merge gate now leaves a receipt in the squash commit: `Gate-*` trailers record the verdict, each blocking row (passed or waived), the override sigils used, any stand-in reviewer, and the merging session and install ids. A gated `gh pr merge` must therefore carry the `--body-file` that `--check-pr` writes. `--check-pr` prints that command in a new `body-file` row, even when other rows block. A merge commit on main with no `Gate-*` trailers did not go through the gate.
