- When the owner rules that a pull request should merge at a particular head, that ruling can now be pinned with a PR comment whose first line is the marker `<!-- genesis-pin head=<sha> -->`, with nothing else on that line; post it as its own comment. Only a pin posted by a maintainer of the repository counts, and a marker on any later line is ignored. A maintainer's comment whose first line starts the marker but is malformed, such as one with a short sha, blocks instead of silently binding nothing. An agent merge then passes only at the pinned head, at any round count, and past the terminal round the terminal-head rule must hold as well, so a pin never loosens it. A pin that names a commit outside the pull request, or two pins that name different heads, block every agent merge. `--check-pr` shows the pin in its `terminal-head` row.
