- When the owner rules that a pull request should merge at a particular head, that ruling can now be pinned with a PR comment carrying `<!-- genesis-pin head=<sha> -->`. Only a pin posted by a maintainer of the repository counts; anyone else's is ignored. An agent merge then passes only at that head, at any round count, and past the terminal round the terminal-head rule must hold as well, so a pin never loosens it. A pin that names a commit outside the pull request, or two pins that name different heads, block every agent merge. `--check-pr` shows the pin in its `terminal-head` row.
