- Only the main session publishes now. A subagent that tries to write to GitHub — `git push`, `gh pr create`, a PR comment or `@codex review` request, a review, a merge, an issue or release write, or a `gh api` write — is refused, with instructions to commit locally and hand the work back to the main session. This includes re-pushes to an existing PR branch and replies to review findings. Fanned-out subagents no longer put one approval prompt per agent in front of you. With `hooks.asks.push_publish: off`, a first push spelled `git -C <a worktree of the same repository> push …`, or followed by `2>&1` and a `| tail -N` / `| head -N` output filter, is now silenced like a plain `git push`.
