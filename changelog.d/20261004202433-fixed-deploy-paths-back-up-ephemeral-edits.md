- Code-only deploys and crash recovery no longer discard local edits to the tracked ephemeral files (`AGENTS.md`, `config/procedure_triggers.yaml`): `scripts/deploy_code_only.sh` and `scripts/bootstrap.sh`'s crash-recovery reset now make the same backup `update.sh` already made, under `~/.genesis/premerge-backups/<run>/`, pruned by the daily disk-hygiene timer after 45 days. A backup that fails leaves the edit in place — the deploy's merge then refuses over it rather than dropping the edit unsaved (#2629, #2632). `update.sh` also refuses before the services stop when a staged edit outside those files would make a 3-way merge fail after the stop, instead of rolling back into an outage (#2628).
