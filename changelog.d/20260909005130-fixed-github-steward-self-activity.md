- **GitHub steward: stop reporting your own activity as someone else's.** A mention notification's actor was resolved as "whoever commented on the thread most recently", falling back to the thread's author when no comment was available. On your own pull requests both answers are *you*, so routine review-bot traffic arrived as a Telegram digest entry with no contributor attached. The actor is now whoever actually WROTE the text naming you, found across all three of a pull request's text surfaces — inline review comments, conversation comments, and review summary bodies — of which only one was previously read at all. A mention that predates the update being reported is no longer re-attributed or re-pinged, and one with no identifiable author is kept rather than mistaken for your own activity. Two real gaps close with it: mentions written in a pull request's review comments or review summaries are now seen, and a response on a pull request you opened on someone else's repo is no longer discarded as self-activity.
