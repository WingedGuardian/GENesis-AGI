- Routing no longer calls `nvidia-nim-deepseek`: NVIDIA accepted DeepSeek V4.1 Flash requests and never answered, so every call waited out its timeout before falling back, and the outage paged as a provider failure. Where it led or sat among paid models, its place is now `deepseek-flash` (DeepSeek's own API, the same V4.1 Flash; needs `API_KEY_DEEPSEEK`, paid) followed by `openrouter-deepseek-flash`. Free-only chains simply drop it. A `gemini-free-latest` provider (Google's `gemini-flash-latest` alias) is declared but not yet in any chain: it currently resolves to the same model as `gemini-free`. Installs without `API_KEY_DEEPSEEK` will see a missing-key warning for these chains; `openrouter-deepseek-flash` still covers them. With these chains, an `API_KEY_DEEPSEEK` now satisfies the onboarding LLM-key floor and an NVIDIA-only key no longer does.
