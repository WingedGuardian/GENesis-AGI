- **The hourly entity-adjudication sweep no longer slows the server's other database queries.** Its fuzzy name comparison ran in a thread that held the Python GIL for about 40 seconds an hour, and other SQLite queries in the server waited for it (one measured query went from 0.15 s to 21 s). It now runs in a fresh child process for each sweep. A crash or a 2-hour timeout fails that hour's job and leaves the sweep cursor in place, so the slice is retried the next hour.
