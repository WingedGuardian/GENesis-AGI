- The CI leak scan (detect-secrets, gitleaks, email, binary-artifact and private-pattern checks) now runs on every push to every non-main branch, not only on pull requests, so a branch published without a PR is still checked. The pull-request check and the new branch check run the same script, `scripts/ci/leak_scan.sh`. On a branch push the private-pattern scan covers every commit the branch carries that main does not, rather than only the newest push.
