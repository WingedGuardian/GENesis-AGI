- **The slot door can start a builder with nobody at the terminal.** `scripts/cc-slot.sh launch --issue N --key K --session-id UUID [--resume] [--slot N] --prompt-file F` starts a slot detached. It never attaches and never prompts. It exits 75 (retry later) when the slot is taken or the box is at capacity, and it reports success only once the session is still running a few seconds later. The builder's claude starts from a rebuilt environment, so it carries no other session's identity, API key or login token. It runs with Remote Control on under the name `build #N`, on the latest Opus model alias, and with the subagent limits in `config/builder_settings.json`. Nothing uses the mode yet: the board launcher that starts builders from the Build column comes next.
