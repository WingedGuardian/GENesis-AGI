- **Browser stack upgraded and installed on every install.** Bootstrap, the installer and the updater now install the browser stack and keep it current: Camoufox 0.5.7 with its Firefox 156 engine (was Firefox 135), Playwright 1.62, and patchright for the Chromium fallback, which hides the automation signals plain Playwright leaves. These packages move only inside the browser step, together with the engine, so a skipped or failed step leaves the previous browser working. The new engine downloads next to the old one, which stays in place until the new engine checks out; then the two are swapped and the old engine is kept as a dated backup. If any step before the swap fails or is interrupted, the step's processes are stopped, the previous browser packages are reinstalled, and any browser package the step added is removed. A run killed outright (SIGKILL, power loss) can leave the browser down until the step is re-run, and a step it had started may keep running; a re-run reports the lock as held until that step ends. The browser tools say when the browser is down. Each browser profile is copied once before a newer browser first opens it. The upgrade is skipped (and says why) while any browser is running or there is under 6 GB free; first install downloads about 2 GB and uses about 3 GB unpacked. Backups are pruned after 14 days once the new engine works. The updater runs this step after the update is recorded as done, so the server's watchdog is not held off during the download. On the update that first ships this, the updater still running is the previous version, so the step is deferred to the next update that applies commits (or run `scripts/install_browser_stack.sh`); the installed browser keeps working meanwhile. After the packages change, Claude Code sessions that were already running must be restarted before their browser tools work; the step says so, and so does the navigate error. The browser tools no longer download an engine mid-call: if it is missing they say so and point to `scripts/install_browser_stack.sh`. A new `browser_automation` capability reports whether the Camoufox package and its pinned engine are installed (the browser step refreshes it without a restart). Web fetches log a warning when Scrapling is unavailable instead of silently using plain HTTP; on a fresh install whose browser step was skipped, that is expected until the step runs.
