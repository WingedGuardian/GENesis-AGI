- `codebase_navigate` can now list extension seams: `seams=True` returns every public Protocol/ABC base with the classes that implement it, including the ones that satisfy it structurally without subclassing it, plus the registry-style places where a new provider, channel, collector or tool is added. `seam="Name"` shows one seam in full. Class entries in the code index now record their base classes; an existing index fills them in on its next run.
