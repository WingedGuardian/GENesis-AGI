- **Untrusted content is handled more strictly at the wrapping boundary.** `ContentSanitizer` now escapes `<` (and its look-alike forms) inside wrapped untrusted content, so wrapped text shows `&lt;` where the original had `<`. Unicode line and paragraph separators become newlines, and a missing value is treated as empty text. Injection-pattern scanning also checks a normalized form of the text that ignores invisible and control characters, so perimeter checks (email, inbox) can block some inbound messages that previously passed.
