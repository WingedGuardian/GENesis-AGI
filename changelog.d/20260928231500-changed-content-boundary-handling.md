- **Untrusted content is normalized before it is wrapped and scanned.** `ContentSanitizer` now treats a missing value as empty text and removes invisible format characters before wrapping, and marker-like text inside wrapped content is rendered inert. Injection-pattern scanning now covers the normalized text as well as the original, so perimeter checks (email, inbox) see the same text that is passed on. This can block some inbound messages that previously passed.
