- **Wrapped untrusted content carries a per-wrap id on both boundary markers.** `ContentSanitizer.wrap_content` now emits `<external-content … id="…">` and a matching `</external-content id="…">`, with a fresh random id for every wrap, and the prompts that read wrapped content say a block ends only at the closing marker that repeats its id. Wrapped text itself is passed on unchanged, apart from Unicode line and paragraph separators becoming newlines and a missing value becoming empty text. `strip_boundary_markers` removes markers with or without an id. Injection-pattern scanning also checks the text as displayed and with invisible and control characters removed, so perimeter checks (email, inbox) can block some inbound messages that previously passed. Code that matched the literal `</external-content>` closing marker must now allow the id attribute.
