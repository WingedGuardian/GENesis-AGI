- **The content-boundary key no longer affects knowledge caching, is read safely, and is backed up.** Knowledge ingestion now hashes page text with boundary markers stripped, so a changed or restored `~/.genesis/boundary_key` no longer makes unchanged pages re-distill. The key file is read only if it is a regular file, without blocking and with a bounded read; anything else falls back to a per-process key with a warning. The encrypted backup now includes the key, and restore stages it with the other credential files.
