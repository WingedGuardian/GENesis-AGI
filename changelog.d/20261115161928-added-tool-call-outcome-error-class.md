- Tool-call outcome rows now store the class of each failure (for example a hook refusal or a user rejection) as the classifier saw it, in a new `error_class` column, and the time each row was recorded, in `recorded_at`. The class depends on text and metadata the row does not keep, so it could not be worked out later; the record time lets a reader tell calls the writer saw live from older calls it picked up when a session resumed.
