- **Browser tools no longer pass a payment card number shown on a page back to the model or into logs.** Every browser tool result and error (page snapshots, `browser_run_js` results, page URLs and titles, exception text) now shows a card number as `[card redacted]`, including one a script returns as a number or as escaped JSON. The health MCP's log lines and tracebacks (`mcp_health.log`, the Turnstile debug log, and FastMCP's tool-error log) are redacted the same way. Detection is the same as the input guards: a known card brand prefix and length plus a valid checksum.
