- **Browser tools no longer pass a payment card number shown on a page back to the model or into logs.** Every browser tool result and error (page snapshots, `browser_run_js` results, page URLs and titles, exception text, the tool-timeout message) now shows a card number as `[card redacted]`, including one a script returns as a number or as escaped JSON. `mcp_health.log` is redacted for every Genesis log line it receives, tracebacks included, and so are the Turnstile debug log, FastMCP's tool-error log and the CAPTCHA Telegram alert's page URL. Detection is the same as the input guards: a known card brand prefix and length plus a valid checksum.
