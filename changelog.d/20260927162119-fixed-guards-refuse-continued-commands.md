- **The safety guards now refuse a command they cannot read line by line.** When a command is split across lines with trailing backslashes and names an operation a guard checks (`git clean`, a force push, a commit, a protected `rm`, a worktree removal, or a `pytest` run), the guard refuses it with a message saying to put the command on one line. The guards also read a checked operation the way the shell assembles it from quotes and backslashes. Continued commands that name nothing a guard checks run as before.
