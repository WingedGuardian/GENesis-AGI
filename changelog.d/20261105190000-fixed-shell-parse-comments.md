- **The guards no longer lose the commands after a comment that holds a quote.** The shell parser did not model `#` comments, so an apostrophe or quote inside one (`# it's`) opened a quote that ran on to the next one, and every command line in between went unseen by the guards. A `#` that starts a word now opens a comment that runs to the end of the line, as in bash. A `#` inside a word (`a#b`, `$#`, `${#v}`) is still ordinary text. Commands that contain a here-doc keep the old scan.
