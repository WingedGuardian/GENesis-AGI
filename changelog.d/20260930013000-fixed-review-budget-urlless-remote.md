- **The commit gate's no-pull-request exemption now works under a global git remote setting.** Any `remote.<name>.*` key in the global git config (for example `remote.origin.prune`) makes git list that remote, with no URL, in every repository that has none. The gate read that empty URL as possibly GitHub, so a scratch repository with no remote still asked for approval on every commit. A remote with no URL is now skipped, since it gives `gh` nothing to resolve; a push-only URL is listed on its own line and still counts.
