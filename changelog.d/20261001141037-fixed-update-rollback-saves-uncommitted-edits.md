- **A failed update no longer throws away uncommitted edits made while it ran.** If another session or editor changed tracked files after `update.sh` merged, and a later step failed, the rollback's reset discarded those edits. Only `AGENTS.md` and `config/procedure_triggers.yaml` were saved. The rollback now snapshots every uncommitted tracked change first, including staged new files, deletions and a file replaced by a directory. The snapshot is kept as `refs/genesis/rollback-save/<time>-<pid>`, and the rollback prints the `git stash apply --index <sha>` command that restores it. The daily disk hygiene prunes these refs after 45 days. When the reset would destroy something the snapshot cannot hold, the rollback does not reset. That covers an edit hidden behind `assume-unchanged`, and an untracked or ignored file where the reset would write. In that case it reports the update as not rolled back and keeps the migrated database to match the code left in place.
