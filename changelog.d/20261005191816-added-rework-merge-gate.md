- **The merge gate now checks the rework contract on rebuilt PRs.** When a PR replaces one that was sent back for rework (labelled `needs-rework` or `needs-architecture-session`), whether it says `Replaces #N` / `Supersedes #N` or its commits contain the old PR's head, the merge is blocked until the old PR carries the builder's `## Rework acknowledgement` comment, posted before the new PR opened, and the new PR's body has a `## Rework` section with `Replaces:`, `Split:`, `Deviations:` and `Questions answered:` lines. `--check-pr` shows this as a new `rework` row. The owner can waive it with `# rework-override`, which is logged.
