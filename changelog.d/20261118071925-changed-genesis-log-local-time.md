- **`genesis.log` now stamps each line in your configured timezone, with its UTC offset.** Lines read like `ts=2026-03-04T13:00:00.123456+01:00` instead of UTC, using the same timezone as the dashboard's Timezone setting. A change there applies at once to the process serving the dashboard (normally the server); any other process writing the file follows it at its next start, so lines around a change can carry different offsets. The offset keeps every line tied to one exact instant, including across a daylight-saving change. An invalid or unreadable timezone falls back to UTC. Stored timestamps in the database are unchanged and stay UTC.
