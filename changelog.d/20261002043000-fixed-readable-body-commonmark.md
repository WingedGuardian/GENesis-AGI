- **Fixed the merge-gate PR-body scanner reading documented examples as real declarations.** `readable_body` now follows CommonMark on the rules it diverged from: a closing fence must be the same character and at least as long as the opener (a ```` block no longer ends at an inner ``` line); lines split only on `\n`, `\r\n` and `\r` (a line joined by NEL or a Unicode line/paragraph separator no longer reads as two); and indentation is judged relative to the enclosing container — a fence inside a list item counts, a `> ```` ` fence inside a quote counts, marker-looking text inside an indented code block is literal content, and an indented line inside a paragraph is a lazy continuation, still text. The `e2e_declaration` fallback scanner carries the same fix so the two body readers stay in agreement.
