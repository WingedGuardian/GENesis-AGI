- **The merge gate now requires a Codex review of the exact head commit; a clean Codex re-review comment no longer counts.** When Codex re-reviews and finds nothing, it posts a comment that names the commit only by an abbreviated id, and an abbreviated id does not identify the commit being merged. The gate still reads that comment and mentions it in its block message. When a clean comment is Codex's only word on the current head, merge with an owner-approved `# substitute-review` resting on a Devin or CodeRabbit review of that exact head. `--check-pr` no longer reports `ok (clean comment at head)`.
