- Claude Code sessions no longer see or store your `secrets.env` values. A new plugin, installed for every session on the install by bootstrap and update, replaces each value with `[secrets.env:VAR]` in tool results, transcripts, saved outputs, background-task output and typed prompts, however a command reached it. Commands still run with the real values, and editing a key in the secrets file still works. Turn it off with `cc_plugins.secret_redact: off` in `~/.genesis/config/genesis.yaml`. See `docs/reference/secret-redaction.md`.
