- **Learned procedures no longer store credentials.** Every procedure write now redacts credential-shaped text (API keys, `NAME=secret` assignments, `sshpass -p <value>`, and `password <value>` in prose) before it is saved, so a login typed during a session cannot be recalled into later ones. `scripts/audit_procedure_secrets.py` reports existing procedures that hold such text, by id and kind only, without changing them.
