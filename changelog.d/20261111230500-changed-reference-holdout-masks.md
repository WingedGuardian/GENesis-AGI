- Saving a credential reference never fails, and never drops part of it, because of where its secret appears. Its name and tags are the only parts that are searched: a secret that appears in either is masked there as `[held]` and the save goes on (a name that needed masking gets a short random tag, and saving under the same masked name again updates that one entry). Everything else the caller sent with it (source details, purpose, caveats, and the name and tags as given) is kept with the secret, outside the search index, and is shown when the credential is revealed. An unknown memory class is stored as `fact`, a missing name is given one, and a body whose shape is ambiguous holds more of itself out instead of being refused. Credentials found in an uploaded file or a distilled document are stored as new entries instead of being refused or replacing an existing one; one that cannot be stored is reported in the document's quality notes. Any reference kind can now hold a value out the same way.
