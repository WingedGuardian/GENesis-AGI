- **The installers no longer report a timezone they did not set.** `host-setup.sh` swallowed a failed `timedatectl` on the host and then printed "+ Timezone: … (host)" anyway. It also printed the container's timezone after a fallback that could leave a dangling `/etc/localtime`. The host leg now prints success only when the host clock reads the zone afterwards (a WARNING with the manual command otherwise), and the container's fallback counts only when the zone file exists. The host is set whenever it differs from your choice, a UTC choice included. A re-run of `install.sh` now takes the zone from `genesis.yaml` (the dashboard's setting) before the deprecated `secrets.env` value, so it sets the clock to the zone Genesis actually uses.
