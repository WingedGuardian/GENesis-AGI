- Claude Code sessions, foreground and background alike, can no longer hand-edit a tracked file in your install's main checkout (the deployed install). File edits, `cp`/`mv`/`install` into it, and `git checkout <ref> -- <paths>` / `git restore --source=<ref>` there are refused with a pointer to work in a worktree and open a PR, so a stray edit can no longer bypass review or leave the tree dirty enough that `scripts/deploy_code_only.sh` refuses to deploy. Untracked files, worktrees, discarding an edit back to HEAD, and the dashboard update's own merge sessions are unaffected. Turn it off with `settings_update("main_checkout_guard", {"enabled": false})` or `GENESIS_MAIN_CHECKOUT_GUARD=0`.
