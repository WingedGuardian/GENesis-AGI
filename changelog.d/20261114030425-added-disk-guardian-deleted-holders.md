- **Added: disk guardian pages now name the processes holding deleted files on the filling disk.** Space held by a file that was deleted while still open (SQLite does this with every spill file) is invisible to `du`, so a nearly full volume could look empty when inspected. The ORANGE and RED pages, and the first log entry of each episode, now list the processes holding such files under the paged path, with how much each holds. Only process names are shown, never command lines.
