- A `gh` listing that is silently capped now says so before it runs. `gh pr list` returns at most 30 items by default, `run list` 20, `workflow list` 50 — so an unflagged listing is already a bounded read with nothing in the command to show it, which is how a count drawn from one can be wrong without looking wrong. It also fires when an explicit `--limit` merely restates the default and therefore changed nothing. Advisory only: never blocks, fires once per listing kind per session, and stays quiet when you passed a limit that actually narrows or widens the read.
