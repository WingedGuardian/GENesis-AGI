- The dashboard no longer serves your API key values, backup target, backup paths or NAS username to a caller that has not logged in. Previously these were included in the API response whenever no dashboard password was configured — the default — so anything that could reach the dashboard port could read them. Setting a password had always protected them; not setting one now withholds them too, rather than disclosing them. The affected panels show the values again once you log in, and nothing else about them changed.
