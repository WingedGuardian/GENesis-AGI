- The dashboard no longer includes your API key values, backup target, backup paths or NAS username in API responses to a caller that has not logged in. Previously these were included whenever no dashboard password was configured, which is the default. Setting a password had always protected them; not setting one now withholds them too. The affected panels show the values again once you log in, and nothing else about them changed.
- If you were already logged in when this update landed, log in again to see those values. Sessions are now bound to the password they were issued against, so a session minted before the update is not recognised for disclosure — the panels will show the fields blank until you do. Changing your dashboard password has the same effect, by design: it retires older sessions from seeing values.
- On an install with no dashboard password set, the login page now says so instead of appearing to log you in. It previously accepted the form and redirected, while creating no session at all — so the protected panels stayed blank with no explanation.
