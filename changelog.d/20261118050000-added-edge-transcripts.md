- **One-call date + text lookup over a transcript store on an edge device.** A new `edge_transcripts` tool lists a day's transcript files on the edge device configured in `ambient_remote.yaml`, or finds a fixed string in them, in one call (status, list, or search with two lines of context). Nothing is copied into Genesis, though the returned lines land in the calling session's transcript and may be extracted into memory like any conversation text. Every background profile denies the tool (no tool exception can lift that), and the tool itself refuses a caller Genesis dispatched with no owner attending and a builder-slot session; it reads those markers from the caller's own environment, so a process started outside both reads as a foreground caller. Search text is returned inside the untrusted-content boundary. A remote failure is reported as an error and a capped read as incomplete, never as an empty result. Set `transcripts_dir` in `ambient_remote.yaml` to enable it; without it the tool reports "not configured".
