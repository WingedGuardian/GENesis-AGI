- **Telegram's reply header names the model that answered, once.** The `[Model / Effort]` line now takes its model from what Claude Code reports it is running (with its version, e.g. `Sonnet 5.5`), not the session record, which could name a different model. The relay now owns the header: a Telegram session is told not to write its own, and the relay prints one on every reply that opens a new Claude Code session, that a failover model answers, or that follows an hour of silence, in direct, group and topic chats alike (drafts show it too where they are sent). Replies Genesis writes itself, such as errors, timeouts, rate-limit notices and contingency answers, carry no header.
