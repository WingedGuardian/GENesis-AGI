- **A resumed code task no longer runs against the main checkout when its worktree folder is an orphan, and no longer loses its committed steps.** Resume now checks that git still lists the folder as a live worktree of this repository, instead of asking git inside it (which walks up to the main repository and says yes), and it re-creates a missing worktree on the task's existing branch rather than deleting that branch first. Worktree checks also ignore `GIT_DIR`-style overrides in the environment (while keeping command-line git config such as `safe.directory`), and the trash refuses to list or restore from a trash folder that is no longer a private directory of yours, or that it cannot read.
