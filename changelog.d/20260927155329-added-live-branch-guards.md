- On an install that runs a local integration branch named `live` (declared by `~/.genesis/deploy_manifest.json`), `git commit` and merge commits on `live` are refused, and on every install a push that would publish a commit carrying a `Deploy-rebuild:` trailer is refused on every remote, so a branch cut from `live` cannot carry other candidates' unreviewed code into a pull request. Cherry-pick, revert and rebase are not covered by these hooks.
