- **`scripts/install_browser_stack.sh` installs the browser packages as one transaction.** The `browser` extra now pins Camoufox 0.5.7 (Firefox 156), Playwright 1.62 and patchright for the Chromium fallback. The script installs it, checks that the installed versions really satisfy the extra (the installer hides pip's exit status), and checks that the installed Camoufox engine suits the new packages; if any of that fails, or the run is interrupted, it stops the step's processes, reinstalls the previous versions of camoufox, playwright and patchright and removes any of those three the run added (their new dependencies stay installed), so the previous browser keeps working. It skips (and says why) while a browser is running, while a Claude Code session holds the browser lock, or with under 6 GB free. If a step's processes survive even a forced kill, it does not start a second pip beside them; it says so and asks for a re-run once they exit. Its last line is the outcome, and it refreshes the `browser_automation` capability.
