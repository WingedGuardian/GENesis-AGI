- Temp protection now starts on a fresh install regardless of where the repo is cloned. `genesis-tmp-watchgod.service` was being installed from a stale second copy of the unit that hardcoded `~/genesis`, so on any checkout somewhere else the service was enabled but could never start, and the installer reported success anyway. Running `bootstrap.sh` (or `update.sh`) had been quietly repairing it; fresh installs went unprotected until then.
