- Temp protection now starts on a fresh install regardless of where the repo is cloned, and the installer says so when it does not. `genesis-tmp-watchgod.service` was being installed from a stale second copy of the unit that hardcoded `~/genesis`, so on any checkout somewhere else the service was enabled but could never start. `systemctl enable --now` reports success for that failure, so the installer did too; it now checks the service is actually running and warns with the reason when it is not, and clears a previously failed unit so a re-run can heal it. Existing installs had the unit FILE repaired by `bootstrap.sh`, but nothing restarted the service — re-running `install.sh` is what picks it up.
