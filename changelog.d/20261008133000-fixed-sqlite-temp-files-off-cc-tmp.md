- **Fixed: SQLite temp files from genesis-server, the bridge and the watchdog no longer land on the Claude Code temp volume.** These units keep `TMPDIR` on `~/.genesis/cc-tmp` on purpose, because the Claude Code sessions they launch need it. SQLite inherited it too, so a large sort or index build spilled a 100-200 MB `etilqs_*` file onto that small volume, and the disk guardian paged it as a runaway file. The units now also set `SQLITE_TMPDIR=~/tmp`, which SQLite reads before `TMPDIR`. Only SQLite's spills move; `TMPDIR` is unchanged. A missing `~/tmp` falls back to `TMPDIR` with no error. Existing installs pick it up when the units are re-rendered (`scripts/update.sh`) and the services restart.
