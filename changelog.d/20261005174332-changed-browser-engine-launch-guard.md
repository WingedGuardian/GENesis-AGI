- **Browser tools no longer download a browser engine mid-call.** Before launching Camoufox, the browser tools now check, by reading files only, that the package and the engine build it is pinned to are installed; if not, they say what is missing and point to the browser-stack installer instead of letting the launch delete an old engine and download a new one inside the tool call. A local browser holds a shared browser-stack lock while it is open, so a launch during a browser-stack upgrade is refused with a message. When the browser packages change on disk after a Claude Code session has already loaded them, the navigate error says to restart the session rather than reinstall. A new `browser_automation` capability reports whether the Camoufox package and its pinned engine are installed. Process detection now also covers patchright's driver.
