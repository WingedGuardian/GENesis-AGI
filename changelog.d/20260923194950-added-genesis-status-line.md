- An optional Claude Code status line, `scripts/genesis_statusline.py`, shows the current branch, the session's open ledger rows, the review-round streak against its cap, and the branch's PR with its review state — `feat/x · ledger:2 · rounds:1/3 · PR#42:approved`. Turn it on with a `statusLine` command in `~/.claude/settings.json` (setup is in the script's header). Because Claude Code allows only one status line, `--then '<command>'` keeps an existing one and prints it underneath. Nothing is enabled by default, and any field it cannot read shows `—` rather than blanking the line.
