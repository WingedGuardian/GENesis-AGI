- `scripts/pr_opener.py <N>` answers which Claude Code session opened a pull request, read-only: from the body's `Opened-by-session:` line as GitHub's edit history first recorded it (the newest stamped version within 120 s of creation, else the oldest, so a later rewrite cannot change the answer), else the first commit's `Genesis-Session` trailer, naming which source answered. An `Opened-by-session-correction:` line in the current body overrides the record. It resolves the session against `cc_sessions` (with its charter mission), never opening a quarantined database, lists every other session that committed to the PR, and names the worktree holding the head branch.
