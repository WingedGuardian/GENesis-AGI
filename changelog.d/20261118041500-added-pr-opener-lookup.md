- `scripts/pr_opener.py <N>` answers which Claude Code session opened a pull request, read-only: from the oldest version of the body that carries an `Opened-by-session:` line (GitHub's edit history keeps every version, so a later rewrite cannot change the answer), else the first commit's `Genesis-Session` trailer, naming which source answered. It resolves the session against `cc_sessions` (with its charter mission), lists every other session that committed to the PR, and names the worktree holding the head branch.
