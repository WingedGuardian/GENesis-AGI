- Archived worktrees whose work is already merged, and which had no uncommitted changes when they were archived, now expire from `~/.genesis/worktree-trash` after 30 days instead of accumulating forever, along with the locked git registration each one kept alive. Archives of UNMERGED work are never expired automatically. Neither are merged archives that held uncommitted changes, or any archive whose status cannot be read. The daily disk-hygiene run deletes the archive first and only then releases and removes its registration, so nothing is un-anchored while its archive still exists. Set `GENESIS_WORKTREE_TRASH_RETENTION_DAYS` to change the window, or `0` to keep all archives. The stranded-work sweep no longer reports every archived worktree as unreadable, and the hygiene run also releases worktree claims left behind by sessions that have exited (`GENESIS_WORKTREE_STALE_CLAIM_RELEASE=0` disables that).
