- Archived worktrees in `~/.genesis/worktree-trash` now expire after 30 days instead of accumulating forever, along with the locked git registration each one kept alive. The daily disk-hygiene run deletes the archive first and only then releases and removes that registration, so nothing is un-anchored while its archive still exists. Set `GENESIS_WORKTREE_TRASH_RETENTION_DAYS` to change the window, or `0` to keep archives indefinitely. The stranded-work sweep no longer reports every archived worktree as unreadable, and the hygiene run also releases worktree claims left behind by sessions that have exited (`GENESIS_WORKTREE_STALE_CLAIM_RELEASE=0` disables that).
