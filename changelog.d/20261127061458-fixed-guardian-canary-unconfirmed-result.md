- **The Guardian's daily auth canary no longer reports success without a result.** A `claude -p` run that exited 0 with empty output, output that was not JSON, or JSON that was not a successful result was recorded as healthy, and could clear an earlier failure with an all-clear page. Only a recognized successful result (`"type": "result"`, `"is_error": false`) now counts as success. Anything else is saved with status `unconfirmed` and a short fixed reason ("exit 0 with empty output", "exit 0 with invalid JSON" or "exit 0 with unrecognized result", never the raw output). It pages like a failure and does not clear one.
