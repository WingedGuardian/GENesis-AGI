- A credential Genesis captures from a conversation is stored only as a new entry: a key that already holds a different value is never replaced, and the capture is kept under a fresh random tag; the same value again adds nothing. Its identifier names the login and has the secret redacted, and when the text still carries part of the secret the capture is kept under a neutral name instead of being lost. A connection string with a password is stored as a credential, and a credential the capture declines never falls back to a url or network entry. Quotes and brackets around a captured value are not part of it, and an UPPER_SNAKE=value line counts only when a whole part of the key names a credential.
